# T22 현재 파일 선택 동기화

탐색기의 마지막 클릭 선택과 현재 에디터 파일이 어긋나던 문제를 수정했다. 파일 변경 시 선택/anchor를 갱신하고 상위 폴더를 펼쳐 필요한 디렉터리를 읽는다. 현재 파일은 공통 선택 배경과 semibold 이름으로 표시한다. 탭은 파일 id를 사용하고 현재 이름을 semibold로 표시하며 공통 탭/행은 aria_selected도 반영한다.

동일 파일 redraw에서는 수동 다중 선택과 접기를 유지한다. 프로젝트 경계·머신·리뷰 스페이스를 검사하며 이전 비동기 읽기가 새 선택을 덮어쓰지 않는다. 프로젝트 전환 시 추적 identity를 초기화한다. 현재 일반 트리는 자동 스크롤 API가 없어 스크롤 위치는 유지한다. 프로젝트 밖 라이브러리 파일은 Project 트리에 행이 없어 선택하지 않는다.

검증: 파일 선택 VM 계약 검사(상위 폴더 펼침, 다중 선택 보존, 경로/머신 경계, 오래된 읽기 무시, 리뷰 스페이스), 공통 시스템 검사, generator --check, activity/codenav native check 통과. 실제 CU에서 KeyCipherTest.kt → MutableClock.kt → KeyCipherTest.kt 탭 클릭 후 각각 탭 강조와 Project의 비활성 선택 행이 함께 이동하는 것을 확인했다. HMR 누적 렌더 오류는 Herdr 재시작 후 해소했으며 기존 터미널과 탭을 유지했다. 리뷰 화면의 실제 왕복과 화면 밖 항목의 자동 스크롤은 검증/구현 범위에 포함하지 않는다.
