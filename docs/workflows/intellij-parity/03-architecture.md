# 설계

idea 레이아웃에만 적용하는 공통 역할을 mods/{codenav,activity}/idea-design.js에 둔다. 두 파일은 동일하게 유지한다. 공통 디자인은 설정에서 읽는 UI 글꼴과 크기, 행·컨트롤·탭 크기, 팝업 표면이다.

셸은 root가 맡고, Project/Find/activity 에디터, 검색·실행·HTTP·컨텍스트 메뉴, 코드·리뷰·코멘트는 서로 파일 경계를 나눠 구현한다. 데이터·키맵·실행 계약을 변경하지 않는다. 기존 공통 helper는 확장하고 중복된 전면 스타일 코드를 피한다.

모서리는 섬 외곽을 소유한 레이아웃에서 보호한다. 본문·뷰어·터미널의 독립 배경이 모서리를 덮지 못하도록 마감 블록과 표면 여백을 쓴다. 팝업은 외곽 배경과 inset된 행을 같은 둥근 표면으로 구성한다.
